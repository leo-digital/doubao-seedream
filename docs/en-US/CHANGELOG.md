# Changelog

## [1.1.1] - 2026-07-15

### Changed

- Updated the plugin icon.

## [1.1.0] - 2026-07-10

### Added

- Added a dedicated **Seedream 5.0-pro** tool using model `doubao-seedream-5-0-pro-260628`.
- Added 1K/2K and official aspect-ratio presets, custom dimensions, PNG/JPEG output, and up to 10 reference images.

### Changed

- Updated plugin metadata and multilingual documentation, with explicit Seedream 5.0 Pro capability boundaries.

## [1.0.1] - 2026-03-06

### Added

- Added the `imageUrls` parameter for passing reference image URLs as a concatenated string.
