# 更新日志

## [1.1.0] - 2026-07-10

### 新增

- 新增 **Seedream 5.0-pro** 独立工具，模型 ID 为 `doubao-seedream-5-0-pro-260628`。
- 支持 1K/2K、官方宽高比预设、自定义尺寸、PNG/JPEG 输出，以及最多 10 张参考图。

### 调整

- 更新插件元数据与多语言文档，并明确 Seedream 5.0 Pro 的官方能力边界。

## [1.0.1] - 2026-03-06

### 新增

- 支持 `imageUrls` 参数，可通过拼接字符串直接传入参考图片 URL。
